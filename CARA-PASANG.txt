CARA PASANG APLIKASI RUTE ANTAR OBAT

1. Ganti tulisan NAMA_ANDA di file index.html dengan nama Anda (ada 2 tempat: di bagian atas dan di bagian bawah halaman).
   Buka file dengan Notepad, tekan Ctrl+H (Ganti), cari NAMA_ANDA, ganti dengan nama Anda.

2. Unggah gratis ke Netlify:
   a. Buka https://app.netlify.com/drop lewat browser.
   b. Tarik (drag) seluruh FOLDER "pwa" ke halaman itu.
   c. Tunggu selesai, Anda mendapat alamat seperti https://nama-acak.netlify.app
   d. (Opsional) Ubah nama alamat di Site settings > Change site name.

   Alternatif: GitHub Pages (unggah folder ke repositori, aktifkan Pages).

3. Pasang di HP:
   - Android: buka alamat itu di Chrome > menu titik tiga > "Instal aplikasi" atau "Tambahkan ke layar utama".
   - iPhone: buka di Safari > tombol Bagikan > "Tambahkan ke Layar Utama".

4. Catatan:
   - Alamat harus HTTPS (Netlify dan GitHub Pages sudah otomatis).
   - Setelah memperbarui file, ubah angka versi di sw.js (rute-obat-v1 menjadi v2) supaya HP mengambil versi terbaru.
   - Data pasien hanya tersimpan di HP masing-masing. Hapus setelah pengantaran selesai.

5. Semua file ada di satu folder (tanpa sub-folder), jadi cukup pilih semua file lalu seret ke GitHub atau Netlify sekaligus.
